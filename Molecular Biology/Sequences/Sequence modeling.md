>[!note]
>We need to model DNA sequences to do things such as make some hypotheses about it, build a generative model to descrive it or find sequences of similar type (in terms of characteristics).
>
>Goals of sequence modeling include:
>- The ability to emit DNA sequences of a certain type
>- The ability to recognise DNA of a certain type
>- Ability to learn distinguishing characteristics of each state

An alignment profile/motif is a model for a specific DNA pattern, however this isn't really practical since all other instances of the pattern are assumed to have the same length $w$.

Once defined the model, we can employ it to find other instances of the pattern in new sequences.

Sequence modeling is probabilistic, and we use tools such as Markov Chains and Hidden Markov Models (HMMs) to model sequences.

### Markov chains and Hidden Markov Models
>[!note]
>A Markov chain is a sequence of data items generated by a model which has one state (node) per symbol/letter and certain transition probabilities between the edges.
>
>In a Hidden Markov Model the model transitions between different states like in a Markov Chain, however the states are not directly observable. Instead, each state has associated emission probabilities to generate certain observable data items.
>
>In other words, we don't know in which state the model is in, we can only observe which characters the model is emitting.
>
>![[Pasted image 20260612162741.png|center]]
>
>We define the transition probability from hidden state $k$ to hidden state $l$: $$a_{kl}=P(\pi_{i}=l |\pi_{i-1}=k)$$
>The emission probability of symbol $x_{i}$ when the hidden state is $k$: $$e_{k}(x_{i})=P(x_{i}|\pi_{i}=k)$$
>The hidden path (sequence of hidden states of a set $\Sigma$): $$\pi=(\pi_{1},\pi_{2},\cdots)$$
>The sequence of observations of a set $V$ of $m$ symbols: $$x=(x_{1},x_{2},\cdots)$$
>The transition matrix that maps the probability of $k\to l$ state transitions: $$A=(a_{kl})$$
>The emission vector that represents the probability of observing the possible observable letters $v_{j}\in V$ from state $k$: $$E_{k}=(e_{k}(v_{1}),\cdots, e_{k}(v_{m}))$$

>[!tip] Definition of a Markov Chain
>A Markov chain is a triplet $(Q,p,A)$ where $Q$ is a finite set of states, where each state corresponds to a symbol in the alphabet $\Sigma$, $p$ is a vector of initial state probabilities, and $A$ is the matrix of state transition probabilities.
>
>The output of the model is the state at each instant time.
>
>The probability of each observed symbol $x_{i}$ depends only on the value of the preceding symbol $x_{i-1}$: $$P(x_{i}|x_{i-1},\cdots,x_{1})=P(x_{i}|x_{i-1})$$
>Therefore the probability of observing a specific sequence $x$ of length $L$ is: $$P(x)=P(x_{L}|x_{L-1})\cdot P(x_{L-1}|x_{L-2})\cdot\space\cdots\space\cdot P(x_{2}|x_{1})\cdot P(x_{1})$$
>Where $P(x_{1})$ is the initial state of probability of $x_{1}$.

>[!tip] Definition of a Hidden Markov Model
>A HMM is a $5$-tuple $(Q,V,p,A,E)$ $Q$ is a finite set of states, where each state corresponds to a symbol in the alphabet $\Sigma$, $V$ is a finite set of observable symbols $v_{m}$ ($|V|=M$), $p$ is a vector of initial state probabilities, $A$ is the matrix of state transition probabilities, and $E$ is a $N\times M$ emission probability matrix with $e_{nm}\equiv P(x_{i}=v_{m}\in V\text{ at step }i|\pi_{i}=q_{n}\in Q)$
>
>Both emissions and transitions are dependent on the current state only and no on the past.
>
>A typical representation of a process which can be modelled by a HMM includes:
>- Start: a random initial state $\pi_{1}\in Q$ according to the initial state probabilities
>- The random choice to move from the current state $pi_{i-1}=k\in Q$ to the next state $\pi_{i}=l\in Q$ that depends on transition probabilities $a_{kl}$
>- For each step $i$ of the hidden path, the hidden state $\pi_{i}$ randomly emits an observable symbol $x_{i}\in V$ according to the emission probabilities $e_{\pi_{i}}(x_{i})$

The probability of observing $x$ in a path $\pi$ in a HMM is: $$\begin{align*}
P(x,\pi)&= P(x|\pi)\cdot P(\pi)=P(\text{emissions}|\text{path})\cdot P(\text{path})\\
&= a_{0\pi_{1}}\cdot \prod_{i} e_{\pi_{i}}(x_{i})\cdot a_{\pi_{i}\pi_{i+1}}
\end{align*}$$
>[!tip] HMM in the context of DNA
>In biology the order of letters matters. A "C" followed by a "G" (often written as CpG) is incredibly important, because "CpG islands" usually mark the start of a gene. If the computer can't remember the previous lettere, it can't find these islands.
>
>To fix this, scientists expand the HMM state space, by weaving the memory directly into the labels. Instead of having just one generic state for the letter "G", they create unique states that look backward: $$A_{+},C_{+},G_{+},T_{+},A_{-},C_{-},G_{-},T_{-}$$
>Where the $+$ marks the base as inside a CpG island, while the $-$ marks the base as outside one.

### Decoding
>[!note]
>Given the model parameters $e_{i}(\cdot)$ and $a_{ij}$, and a sequence of emissions $x$ we can find the sequence of hidden stats $\pi$ using the Viterbi algorithm.
>
>We define $V_{k}(i)$ as the probability of the most likely path through state $pi_{i}=k$, and we compute: $$V_{k}(i+1)=e_{k}(x_{i+1})\cdot \max_{j}a_{jk} V_{j}(i)$$
>We need to find the path $\pi^{*}$ that maximises the total join probability $P[x,\pi]$. Assuming we know $V_{j}$ for the previous time step, we can calculate: $$V_{k}(i)=e_{k}(x_{i})\cdot \max_{j}(V_{k}(i-1)\cdot a_{jk})$$
>![[Pasted image 20260612172311.png|center]]
>We initialise $V_{0}(0)=1$ and $V_{k}(0)=0\quad\forall k>0$. Calculating iteratively the previous value, and following max pointer back we can find: $$P(x,\pi^{*})=\max_{k}V_{k}(n)$$
>This algorithm has a time complexity of $\mathcal{O}(k^{2}n)$ and a space complexity of $\mathcal{O}(kn)$.

### Evaluation
>[!note]
>Given the model parameters $e_{i}(\cdot)$ and $a_{ij}$, and a sequence of emissions $x$ we can find the total probability of generating a given $x$ over any path, that is: $$P(x)=\sum\limits_{\pi}P(x,\pi)=\sum\limits_{\pi}P(x|\pi)\cdot P(\pi)$$
>To calculate it we define the forward probability as: $$f_{I}(i)=e_{I}(x_{i})\sum\limits_{k}f_{k}(i-1)a_{kl}$$
>Assuming we know $f_{j}$ for the previous time step, we can calculate: $$f_{k}(i)=e_{k}(x_{i})\cdot\sum\limits_{j}f_{j}(i-1)\cdot a_{jk}$$
>![[Pasted image 20260612173354.png|center]]
>We initialise $f_{0}(0)=1$ and $f_{k}(0)=0\quad\forall k>0$. We then calculate: $$P(x,\pi^{*})=\sum\limits_{k}f_{k}(n)$$
>This algorithm has a time complexity of $\mathcal{O}(k^{2}n)$ and a space complexity of $\mathcal{O}(kn)$.

### Posterior decoding
>[!note]
>To find the likelihood that an emission $x_{i}$ is generated by a state in a specific position, we can use posterior decoding, that looks at the entire DNA sequence to decide what is happening in a specific position. To do this it has to calculate and add up every single possible path that could have led to that base, and every path that could follow it: $$P(\pi_{i}=k,x)=P(x_{1}\cdots x_{i}|\pi_{i}=k)\cdot P(x_{i+1}\cdots x_{n}|\pi_{i}=k)$$
>
>To calculate the backward probability we compute: $$b_{k}(i)=\sum\limits_{i}(e_{I}(x_{i+1})\cdot a_{kl}\cdot b_{I}(i+1))$$
>![[Pasted image 20260612180331.png|center]]
>By initialising $b_{k}(n)=a_{k0}\quad\forall k$, we can compute: $$P(x)=\sum\limits_{l}a_{0l}\cdot e_{l}(x_{1})\cdot b_{l}(1)$$
>This algorithm has a time complexity of $\mathcal{O}(k^{2}n)$ and a space complexity of $\mathcal{O}(k)$.
>
>We can then evaluate: $$P(k)=P(\pi_{i}=k|x)=\frac{f_{k}(i)\cdot b_{k}(i)}{P(x)}$$
>We also define $\hat{\pi}_{i}=\arg\max_{k} P(\pi_{i}=k|x)$.

### Supervised learning
>[!note]
>Given a string of DNA, where every single CpG island is explicitly highlighted, it's possible to use supervised learning to train a model with basic parameters. Given $A_{kl}=\#\text{times }k\to l\text{ transition occours in }\pi$, and $E_{k}(b)=\#\text{ times state } k\text{ in }\pi\text{ emits in }x$, we can show that the maximum likelihood parameters $\theta$ are: $$a_{kl}= \frac{A_{kl}}{\sum\limits_{i}A_{ki}}\qquad e_{k}(b)= E_{k}\frac{b}{\sum\limits_{c}E_{k}(c)}$$

Given very little data, there may be overfitting, that means those formulas may say the probability is $0$. To prevent the model from exploding. we add a pseudocount, a tiny fake number, to every single possibility.

### Unsupervised learning
>[!note]
>Sometimes we may not know the true values of $A_{kl}$ and $E_{k}(b)$, and we may not know where CpG islands are.
>
>To fix this, we estimate our "best guess" on what those values are, using maximum-likelihood estimation, we update the probabilistic parse of our sequence based on these parameters, and we iterate.

>[!tip] Viterbi Training
>The Viberbi training approach performs Viterbi to find $\pi^{*}$, it calculates $A_{kl}$ and $E_{k}(b)$ according to $\pi^{*}+\text{pseudocounts}$, and then calculates the new parameters $a_{kl},e_{k}(b)$. This is repeated until convergence.

>[!tip] Baum-Welch Algorithm
>The Baum-Welch algorithm picks the best guess for model parameters, and then uses the forwards and backwards algorithms to calculate a weighted average across all possible paths. It then calculates $A_{kl}$ and $E_{k}(b)$, and calculates the new model parameters $a_{kl}$ and $e_{k}(b)$. This is repeated until $P(x|\theta)$ doesn't change much.
>
>This has a time complexity of: $$\#\text{ iterations}\cdot \mathcal{O}(k^{2}n)$$
>And it's not guaranteed to find globally best parameters.
